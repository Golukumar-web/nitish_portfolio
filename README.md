# ⚖️ Advocate Nitish Giri — Legal Portfolio Website

A modern, responsive and professional portfolio website designed for **Advocate Nitish Giri**. The website provides information about legal practice areas, services, client testimonials, consultation booking and contact options.

## 🌐 About the Project

This website is designed to provide a professional online presence for a legal advocate and make it easy for visitors to:

* Learn about the advocate
* Explore different practice areas
* View legal services
* Request a consultation
* Send a message
* Contact the advocate through phone, email or WhatsApp

## ✨ Features

* 🏠 Modern Home/Hero section
* 👨‍⚖️ About Advocate section
* ⚖️ Practice Areas section

## 🚀 How to Run the Project

1. Download or clone this repository.

2. Open the project folder.

3. Open `index.html` in a web browser.

Or, if you are using VS Code, install the **Live Server** extension and open the project using Live Server.

## 📩 Formspree Setup

The website uses Formspree to handle the **Appointment Request** and **Contact** forms.

To configure the forms:

1. Create a Formspree account.
2. Create a new form.
3. Copy the Formspree form endpoint.
4. Add the endpoint to the `action` attribute of the HTML form.
